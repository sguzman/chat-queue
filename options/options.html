Chat Queue preferences

System follows your desktop light/dark preference. The choice is shared between the queue HUD and this preferences page.

Extension API permissions

No other extension receives queue access unless you approve its exact Firefox extension ID and explicit scopes. Scopes: discover (tab metadata/events), read (queued prompt text/history), append (add messages), edit (change/delete/reorder), control (Start/Pause). These are independent; grant only what is needed.

API namespace: chat-queue/v1. Add-on ID: chat-queue@sguzman.github.
